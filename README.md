# CHAT 老化时间推算

基于 UL/IEC 60691 Annex C 的导体耐热老化排程与时间推算工具。

在线网站：<https://chat-aging-time-calculator.vercel.app/>

## 使用

直接打开 `index.html`，或在项目目录运行任意静态文件服务器。输入试验开始时间、测试结束总时长（包含加热与休息）以及额定温度 Tf，即可查看当前阶段、剩余时间、A–G 阶段时间轴和详细动作排程。

## 排程规则

- A–F 阶段依次按 Tf−35 K、Tf−25 K、Tf−20 K、Tf−15 K、Tf−10 K、Tf−5 K 进行。
- 每周循环为 60 h 加热、12 h 休息、36 h 加热、12 h 休息、72 h 加热，共 192 h。
- 阶段 G 为 Tf+5 K，持续 24 h。
- 完整排程为 1560 h，包含全部休息时间。
